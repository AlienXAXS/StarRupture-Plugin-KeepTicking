- KeepTicking now takes its game values from the mod loader's version object map (the version map), so the same DLL runs on every supported server build. On CL 127004, the current 0.3.5 server, it also finds the pause function by its own byte pattern. If neither the version map nor the pattern finds it on a newer server build, the plugin is refused and the log says why ("will NOT be loaded")
- The three game members the idle check uses (the net driver, its client connections and the world's time dilation) are read through the game's reflection data instead of fixed offsets
- Building: plain Debug and Release stop with an error that names the Server configurations
- Needs mod loader v1.25.0 or newer
